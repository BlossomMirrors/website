# BlossomOS Switch

BlossomOS Switch migrates apps, files, and settings from Windows to BlossomOS.

- App migration: scans installed Windows software and lines up Linux alternatives, ready to install with one click.
- Moves documents, photos, and music to the right places automatically.
- Carries over keyboard shortcuts, accessibility, and display preferences.
- Exports browser bookmarks, history, and saved passwords cleanly.
- Three steps: run Switch on Windows to snapshot apps/files/settings, install BlossomOS, Switch finishes the job on first boot.
- GDPR by design, fully auditable (open source), no vendor lock-in, license-free (paid support plans available for organisations).
- Windows 10 extended support ends October 14, 2027.

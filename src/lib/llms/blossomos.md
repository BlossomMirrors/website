# BlossomOS

BlossomOS is a free, open source Linux desktop built by Blossom Labs, on top of KDE Plasma with BlossomOS's own BlossomUI design layer.

- Runs on KDE Plasma: a mature, open-source desktop, stable, powerful, and accountable to no one but its community.
- BlossomUI is BlossomOS's own design layer on top of Plasma: a modern, consistent UI design across the whole system.
- Core apps like the file manager and system settings are forked and redesigned by Blossom Labs.
- Immutable Core: the system updates itself as a whole image, every update built and tested as a complete system before it ships. Nothing is ever half-updated, and any update can be rolled back from System Settings or the boot menu, with your files and settings left exactly as you left them.
- Separate from Arc, pkglayer lets you use the package manager commands you already know, dnf, yay, apt, apt-get, nix, emerge, on top of the immutable core. Most people won't need it since Arc installs everything with one click, but the option is there.
- Open Source: every line of code is open for inspection, so security researchers, EU regulators, users, and hardware partners can verify it is secure, private, and free of hidden telemetry.
- Security Built In: state-of-the-art offline encryption and hardware-assisted security features from the start, full disk encryption out of the box.
- No data collection, no forced updates, no built-in ads, no AI you didn't want.
- Runs well on older hardware thanks to optimizations.
- Gaming: Steam and thousands of titles via Proton, high performance, low latency.
- Business: LibreOffice, Thunderbird, enterprise-grade encryption, EU-hosted cloud storage out of the box, GDPR-compliant by design, no dependency on foreign vendors, paid support available.
- To install: a USB stick with 16 GB or more, a modern 64-bit computer (built after 2010), more than 35 GB free disk space, and 2 GB RAM or more.
- Download the ISO from blossomos.org: the standard ISO for Intel/AMD GPUs, or the NVIDIA ISO if you have an NVIDIA graphics card. The site usually detects your GPU automatically and suggests the right file.
- Free forever, no credit card, no catch.

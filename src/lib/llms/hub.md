# Blossom Hub

Blossom Hub is a central management platform for organisations running BlossomOS, coming soon.

- Devices, users, policies, and software deployment, with no vendor lock-in and full EU data protection compliance.
- Company dashboard, team management with roles/groups, silent or scheduled software deployment with approved software lists, policy enforcement (disk encryption, peripheral access), single sign-on, audit logs, remote enrolment/wipe/configuration, multi-site support.
- Built for IT teams, schools, and small businesses.

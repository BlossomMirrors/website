# Blossom Cloud

Blossom Cloud is EU-hosted cloud storage and collaboration built for BlossomOS.

- File sync across every device, EU datacenters, video calls with no third-party accounts, and settings sync (desktop preferences, wallpaper, app settings) across every BlossomOS install.
- Every file is protected with AES-256 encryption, all traffic secured with TLS. Servers are located in the EU, subject to GDPR.
- Free to start, no credit card required.

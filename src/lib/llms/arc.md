# Arc

Arc is the software store built for BlossomOS, unifying every Linux package format into one click.

- The Linux software ecosystem is fragmented: Flatpak here, AppImage there, deb and rpm packages somewhere else. Arc Unify brings every format together, so apps that would otherwise need manual dependency hunting or extra setup just install with a click.
- Arc Unify handles Flatpak, AppImage, Arch Linux packages, deb, and rpm through one consistent interface. Flatpak apps come from Flathub, already sandboxed; a deb, rpm, or Arch package gets installed inside its own isolated container instead.
- Installing is one click, with a dedicated section showing active, pending, and completed downloads. Updates install in the background automatically by default, or on demand via Update All.
- Arc Winapps brings Windows-only software to BlossomOS through Wine. Apps appear in the store, launch like native apps, and integrate with the desktop. No dual-boot, no VM management.
